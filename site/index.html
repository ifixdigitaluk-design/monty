Installing on Windows
  1. On the release page, download the file ending in -setup.exe (or .msi).
  2. Run it. The app isn’t code-signed yet, so Windows may say “Windows protected your PC”: choose More info → Run anyway.
  3. Open Monty from the Start menu and sign in with your work account.
New to Monty?

Ask your administrator for an invitation. Open the link in the invitation email, create your account, then confirm your email address from the message we send you.
